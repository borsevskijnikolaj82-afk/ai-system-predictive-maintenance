# ADR-02: Хранение и версионирование моделей
- **Статус:** Accepted
- **Контекст:** Бинарные веса велики и должны иметь управляемые версии.
- **Рассмотренные альтернативы:** хранить веса в Git; хранить артефакты в S3/MinIO или MLflow.
- **Решение:** бинарные веса не коммитятся в Git; метаданные/версии фиксируются в Git, артефакты — во внешнем model storage.
- **Обоснование:** Разделение исходного кода и крупных бинарных артефактов.
- **Последствия:** Нужна внешняя инфраструктура хранения и политика доступа.
