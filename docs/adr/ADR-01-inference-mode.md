# ADR-01: Синхронный REST API для инференса
- **Статус:** Accepted
- **Контекст:** Нужен простой контракт одиночного предсказания с низкой задержкой.
- **Рассмотренные альтернативы:** synchronous REST; asynchronous Message Queue.
- **Решение:** FastAPI + синхронный REST `POST /api/v1/predict`.
- **Обоснование:** Соответствует учебному кейсу, упрощает реализацию и отладку, подходит для одиночных запросов.
- **Последствия:** Простой клиентский контракт; при росте нагрузки может потребоваться очередь и отдельный serving.
