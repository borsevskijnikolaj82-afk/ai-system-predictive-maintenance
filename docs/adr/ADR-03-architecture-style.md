# ADR-03: Модульный монолит
- **Статус:** Accepted
- **Контекст:** Учебный проект с небольшой нагрузкой и необходимостью быстро тестировать архитектуру.
- **Рассмотренные альтернативы:** modular monolith; microservices.
- **Решение:** единый Docker-контейнер с логически независимыми модулями.
- **Обоснование:** Нет избыточных сетевых задержек, проще локальная разработка и тестирование.
- **Последствия:** Масштабирование частей независимо ограничено; при существенном росте нагрузки возможна декомпозиция.
